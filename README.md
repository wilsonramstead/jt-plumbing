# JT Plumbing — Demo Site

Single-page demo website for **JT Plumbing** (listed as "Jt Plumbing"), a plumber in
Marina, CA serving the Monterey Peninsula. Built as a sales demo by Wilson Innovations.

- **Live demo:** https://wilsoninnovations.net/jt-plumbing/
- **Business:** JT Plumbing — 3016 Del Monte Blvd, Marina, CA 93933
- **Phone / CTA:** (831) 632-0139 (tel: — no contact forms)
- **Google:** 4.4★ across 21 reviews
- **Hours:** Open 24 hours, 7 days a week (per Google listing — 24/7 claim is factual)

## Build notes
- Single self-contained `index.html`, inline CSS + minimal JS. Works from `file://`
  and with JS disabled.
- **Fonts:** Spectral SC (display) + Rosarivo (body), via Google Fonts.
- **Palette:** deep water-blue (`#0b2434` / `#0f3348`) + copper-pipe accent (`#bd7440`),
  with aqua highlights — differentiated from sibling plumbing builds.
- `noindex` while it's a demo (see comment at top of `index.html`); remove when live.
- Mobile header: copper call button flush right at all widths; icon-only ≤600px.
- Footer credit: "Website by Wilson Innovations" → https://wilsoninnovations.net
- LocalBusiness (Plumber) JSON-LD with real address, phone, 24h hours and 4.4/21 rating.

## Facts / honesty
Only facts from the lead data are used. No invented email, license numbers, founding
year, staff, or certifications. The 24/7 availability claim reflects the Google listing's
"Open 24 hours" every day. Testimonials are drawn from real Google reviews (first name +
last initial). "Our Work" gallery images are labeled **Example** stock photos, to be
swapped for JT Plumbing's own project photos after the sale.
